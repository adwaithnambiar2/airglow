# Third-party components

Airglow includes the following unmodified external assets to support local, offline hand tracking:

- **MediaPipe Tasks Vision 0.10.21**, Google LLC. JavaScript bundle and SIMD / non-SIMD WebAssembly loaders and runtimes. Apache License 2.0. Source: https://github.com/google-ai-edge/mediapipe. Distribution: https://www.npmjs.com/package/@mediapipe/tasks-vision/v/0.10.21.
- **MediaPipe Hand Landmarker, float16, version 1**, Google. Pretrained model task bundle: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task. Documentation: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker.

The MediaPipe license text is included at `vendor/mediapipe/LICENSE`. Copyright and license notices embedded in third-party files are retained. The project's MIT license applies to original project code; third-party assets retain their applicable licenses.

The images in `docs/` are actual screenshots of Airglow's drawing interface using its built-in example curves. They are not webcam inference results.
